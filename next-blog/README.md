# Արմինեի Next.js բլոգը

Վեցերորդ ուսումնական նախագիծ՝ Next.js App Router, React և TypeScript։

## Գործարկում

Այս պանակում՝

```sh
npm install
npm run dev
```

Բացիր `http://localhost:3000/next-blog/`։ Windows PowerShell-ում անհրաժեշտության դեպքում օգտագործիր `npm.cmd`։

## Կառուցվածքը

- `app/page.tsx` — հոդվածների ցանկ։
- `app/layout.tsx` — ընդհանուր նավիգացիա և ստորին հատված։
- `app/posts/[slug]/page.tsx` — հոդվածի էջ, ստատիկ հասցեներ և metadata։
- `lib/posts.ts` — երեք հայերեն ուսումնական հոդված։ Ավելացրու նոր գրառում այստեղ։
- `app/globals.css` — responsive ձևավորում։

`npm run build`-ը ստեղծում է `out/` ստատիկ տարբերակը։ Այն պետք է հրապարակել պորտֆոլիոյի `/next-blog/` հասցեում։ `basePath`-ը դրա համար սահմանված է `next.config.ts`-ում։ Սա տեղական տվյալներով բլոգ է, առանց խմբագրման վահանակի կամ տվյալների բազայի։

Build-ից հետո `postbuild`-ը պատրաստ էջերը պատճենում է այս պանակում, որպեսզի հիմնական պորտֆոլիոյի Live Server հղումը՝ `/next-blog/`, աշխատի։ Կոդի փոփոխություններից հետո կրկին գործարկիր `npm run build`, կամ կենդանի փոփոխությունների համար օգտագործիր `npm run dev`։

Առաջին վարժությունը՝ `lib/posts.ts`-ում փոխիր հոդվածի վերնագիրը և տես՝ ինչպես է փոխվում էջը։
