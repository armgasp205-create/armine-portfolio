# Ասո Եղոյան · Վարսահարդար և բարբեր

Առանձին կայք Գյումրիի վարսահարդարի համար։ Բաց, մինիմալ դիզայն՝ կաթնագույն ֆոնով, մուգ տեքստով և մեղմ կանաչ շեշտերով։ HTML, CSS և JavaScript, առանց build-ի անհրաժեշտության։

Բացիր `index.html`-ը բրաուզերում կամ այս պանակը գործարկիր Live Server-ով։ Առանձին preview՝ `node aso-barber/preview.mjs`, հասցե՝ `http://127.0.0.1:5180/`։

Ծառայությունների երեք անվանումներն օրինակային առաջարկ են՝ հաստատել վարպետի հետ։ Հեռախոսը՝ +374 77 834023, Instagram՝ aso_exoyan, տրամադրված են օգտատիրոջ կողմից։ Գներ, կոնկրետ հասցե, աշխատանքային ժամեր և իրական աշխատանքների նկարներ չեն հորինվել։ Hero-ի պատկերն SVG նկարազարդում է, ոչ վարպետի աշխատանքի լուսանկար։

Կապի հաստատված տվյալներն ավելացվում են `script.js`-ի `contact` օբյեկտում։ Այցի ձևը պատրաստում և պատճենում է հարցման տեքստ․ այն տվյալներ չի ուղարկում, իրական ամրագրում կամ ազատ ժամերի ստուգում չի կատարում։

Այս պանակը անկախ է նախկին պորտֆոլիոյից և դրա հրապարակման workflow-ի մեջ չի ներառված։ Առանձին հրապարակման համար անհրաժեշտ է ընտրել հոսթինգը կամ նոր GitHub repository։
