# Ինչպես է աշխատում ծախսերի հաշվիչը

Բացիր `src/pages/ExpensesPage.tsx`։ Այստեղ միասին կիրառված են React, TypeScript և JavaScript։

## 1. Տվյալի կառուցվածքը՝ TypeScript

```ts
interface Expense {
  id: string;
  title: string;
  amount: number;
  category: string;
  date: string;
}
```

Ամեն ծախս ունի իր նույնացուցիչը, անվանումը, գումարը, կատեգորիան և ամսաթիվը։ Գումարը պահում ենք հարյուրերորդական դրամներով ամբողջ թվի տեսքով՝ գումարման կլորացման սխալները նվազեցնելու համար։ Օրինակ՝ 25.50 դրամը պահվում է որպես 2550։

## 2. Փոփոխվող տվյալները՝ State

```tsx
const [expenses, setExpenses] = useState<Expense[]>(readExpenses);
```

`expenses`-ը ծախսերի ընթացիկ ցուցակն է։ `setExpenses`-ը փոխում է այդ ցուցակը, և React-ը թարմացնում է էկրանը։ `Expense[]` նշանակում է ծախսերի զանգված։ `readExpenses`-ը սկզբում կարդում է պահպանված տվյալները։

## 3. Ավելացնել՝ առանց հին տվյալները փոխելու

```tsx
setExpenses(previous => [newExpense, ...previous]);
```

Սա պարզեցված օրինակ է․ `newExpense`-ը նոր ծախսի օբյեկտն է։ `previous`-ը նախորդ ցուցակն է, իսկ `...previous`-ը դրա բոլոր տարրերը տեղադրում է նոր զանգվածում։ Նոր ծախսը հայտնվում է առաջինը։

## 4. Ընդհանուր գումարը՝ reduce

```ts
const total = visible.reduce((sum, expense) => sum + expense.amount, 0);
```

Սկսում ենք 0-ից և հերթով ավելացնում յուրաքանչյուր ցուցադրված ծախսի գումարը։ Սա հաշվարկ է, առանձին state պետք չէ։

## 5. Պահպանում՝ useEffect և JSON

```tsx
useEffect(() => {
  localStorage.setItem(storageKey, JSON.stringify(expenses));
}, [expenses]);
```

Ցուցակի փոփոխության դեպքում այն վերածվում է JSON տեքստի և պահվում բրաուզերում։ Իրական կոդում նաև մշակվում է պահպանման հնարավոր սխալը։ Այլ հեռախոսում տվյալներն ինքնաբերաբար չեն հայտնվում․ դրա համար հետագայում անհրաժեշտ կլինի սերվեր կամ տվյալների բազա։

Փորձիր ավելացնել 500 և 1200 դրամ ծախսեր․ ընդհանուր գումարը կլինի 1700։ Ջնջիր 500-ը․ կմնա 1200։ Թարմացրու էջը՝ պահպանված ծախսը պետք է մնա։
