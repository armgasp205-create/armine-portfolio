# Առցանց հաշվի միացում

Կոդը պատրաստ է Supabase Auth և Postgres ծառայություններին միանալու համար։ Մինչ նախագծի կարգավորումը՝ հավելվածը շարունակում է տեղային աշխատանքը և «Իմ հաշիվը» էջում բացատրում է, որ ծառայությունը միացված չէ։

## Միացման քայլերը

1. Բացիր https://supabase.com/dashboard և ստեղծիր հաշիվ ու նախագիծ։
2. Նախագծի SQL Editor-ում գործարկիր `supabase/schema.sql` ֆայլի ամբողջ պարունակությունը մեկ անգամ։
3. Authentication-ի URL Configuration-ում Site URL-ը սահմանիր `https://armine-web.netlify.app/react-planner/`։ Redirect URLs-ում ավելացրու նույն հասցեն և տեղային փորձարկման համար `http://localhost:5173/`։ Հաստատման հղումից հետո կարող ես բացել «Իմ հաշիվը» էջը։
4. Նախագծի Connect պատուհանից կամ API կարգավորումներից վերցրու Project URL-ն ու **publishable key**-ը։ Գաղտնի բանալի պետք չէ։
5. Netlify նախագծի environment variables-ում ավելացրու `VITE_SUPABASE_URL` և `VITE_SUPABASE_PUBLISHABLE_KEY`, ապա նոր deploy արա։ Vite-ը կարդում է դրանք build-ի ընթացքում։
6. Տեղային փորձարկման համար պատճենիր `.env.example`-ը `.env.local` անունով, լրացրու արժեքները և վերագործարկիր dev server-ը։ `.env.local`-ը Git-ում չի պահվում։

## Ինչպես է աշխատում

- «Իմ հաշիվը» էջում կա էլ․ փոստով և գաղտնաբառով գրանցում ու մուտք։ Գրանցման հաստատումը կառավարում է Supabase-ը։
- «Պահպանել առցանց»-ը պահում է առաջադրանքները, ծախսերը և բոլոր ամիսների բյուջեները մեկ տարբերակով։
- Մյուս սարքում մուտք գործիր նույն հաշվով և սեղմիր «Բեռնել առցանցից»։ Բեռնումը պահանջում է հաստատում և փոխարինում է սարքի տվյալները։
- Ավտոմատ համաժամացում չկա։ Սարքերը փոխելիս նախ բեռնիր, փոփոխություններից հետո՝ պահպանիր։
- Հին տարբերակով պահպանումը մերժվում է, եթե այլ սարքում արդեն նոր փոփոխություն է պահպանվել։ Տվյալների բազայում RLS-ը թույլ է տալիս հաշվի սեփական տվյալների հասանելիությունը։
- Բեռնումից առաջ հին տեղային տարբերակը պահվում է `armine-before-cloud-restore` բանալիով՝ այս բրաուզերում։ Դուրս գալը տեղային տվյալները չի ջնջում։ Ընդհանուր սարքում մաքրիր կայքի տվյալները։

## Իրական ծառայությամբ ստուգում

Մինչ իրական URL-ն ու բանալին չկան, հնարավոր չէ ստուգել գրանցումը, նամակների առաքումը կամ SQL կանոնները իրական ծառայության վրա։ Միացումից հետո ստուգիր երկու հաշիվներով՝ երկրորդը չպետք է տեսնի առաջինի գրառումները։ Ստուգիր նաև երկու սարքով պահպանում/բեռնում և հին տարբերակի մերժում։

Պաշտոնական աղբյուրներ՝ [Auth](https://supabase.com/docs/reference/javascript/auth), [գրանցում](https://supabase.com/docs/reference/javascript/auth-signup), [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)։
