Իմ մասին

Տեղեկատվական տեխնոլոգիաների մագիստրոս եմ և զարգացնում եմ Front-End ծրագրավորման հմտություններս։ Ուսումնական նախագծերում կիրառել եմ HTML, CSS, JavaScript, React և TypeScript։ Կառուցել եմ responsive էջեր, ինտերակտիվ ձևեր, որոնում ու զտիչներ, API-ից տվյալների բեռնում և բրաուզերում պահպանում։ Փնտրում եմ սկսնակ Front-End ծրագրավորողի կամ պրակտիկանտի հնարավորություն։

Կրթություն

Հայաստանի ազգային պոլիտեխնիկական համալսարան, Գյումրու մասնաճյուղ

Տեղեկատվական տեխնոլոգիաներ · Մագիստրոսի աստիճան
Ավարտել եմ՝ 2018 թ.

Հմտություններ

Կիրառված են ուսումնական նախագծերում։

  • HTML, CSS՝ էջերի կառուցվածք, ձևեր, Flexbox/Grid, responsive դասավորություն, media queries և թեմաներ։
  • JavaScript՝ DOM, իրադարձություններ, ֆունկցիաներ, զանգվածներ, օբյեկտներ, որոնում, զտում և հաշվարկներ։
  • API և պահպանում՝ fetch, async/await, JSON, localStorage, բեռնման ու սխալի վիճակներ։
  • React՝ components, props, useState, useEffect, Context, React Router և կառավարվող ձևեր։
  • TypeScript՝ տվյալների տիպեր, interfaces, union types և React բաղադրիչների տիպավորում։
  • Գործիքներ՝ VS Code, Git, GitHub, npm, Vite, Netlify։

Շարունակում եմ խորացնել React/TypeScript-ը, debugging-ը, մատչելիությունը, թեստավորումը և տվյալների բազաների հետ աշխատանքը։

Ուսումնական նախագծեր

Modern Shop

Ապրանքների որոնում, զտում, դասավորում, զամբյուղի քանակի կառավարում, գումարի հաշվարկ և տեղային պահպանում։ HTML, CSS, JavaScript։ Վճարման համակարգ չի ներառում։

Admin Dashboard

Պատվերների զտում ըստ ժամանակահատվածի ու կարգավիճակի, ցուցանիշների և գրաֆիկի վերահաշվարկ, CSV արտահանում։ HTML, CSS, JavaScript։ Օգտագործում է ցուցադրական տվյալներ։

Weather App

Քաղաքի որոնում, ընթացիկ եղանակ և հնգօրյա կանխատեսում Open-Meteo API-ից։ Բեռնման և սխալի վիճակներ, հին հարցումների չեղարկում։ HTML, CSS, JavaScript։

Music Player

Երեք սինթեզված մեղեդի, pause/resume, ձայնի տեղափոխում, մեղեդու ընտրություն և ուժգնության կառավարում։ HTML, CSS, JavaScript, Web Audio API։

Իմ օրը — React + TypeScript

Առաջադրանքներ, որոնում, զտիչներ, առաջընթաց, ծախսերի խմբագրում, ամսական բյուջե և մնացորդ։ React, TypeScript, Context, React Router, Vite, localStorage։ Supabase-ի ինտեգրումը վերջնական փորձարկման փուլում է։
