# Մուտք և իրավունքներ

Տեղական սերվերը նույն Supabase հաշիվն է օգտագործում, ինչ React-ի «Իմ հաշիվը» էջը։ Գաղտնաբառը ուղարկվում է Supabase-ին։ Node.js-ը ստուգում է մուտքի token-ը Supabase Auth-ի `/auth/v1/user` հասցեով յուրաքանչյուր պաշտպանված հարցման ժամանակ։ Հաճախորդից ստացված role-ը չի ընդունվում։

Ադմինը՝ հաստատված `armine.gasparyan94@mail.ru` հասցեի հաշիվն է։ Այն կառավարում է ապրանքները, հոդվածները, պատվերների կարգավիճակները և կարդում հաղորդագրություններն ու գործողությունների պատմությունը։ Մնացած հաշիվները կարող են կառավարել միայն իրենց առաջադրանքները՝ ներառյալ որոնումը, վիճակագրությունը, աղբարկղը և ներմուծում/արտահանումը։

Հին՝ հաշիվ չունեցող առաջադրանքները առաջին անգամ ադմինի կողմից բացելիս կցվում են այդ ադմինին։ Մյուս հաշիվները դրանք չեն տեսնում։ Բազան չի ջնջվում։ Այլ հաշվի հետ նույն ID ունեցող ներմուծումը մերժվում է ամբողջությամբ՝ առանց մասնակի գրառումների։

Մուտքը՝ http://127.0.0.1:3002/react-planner/#/account ։ Մուտքից հետո բացիր «Իմ սերվերային առաջադրանքները» կամ «Կառավարման էջ»։ Առանձին կառավարման էջի համար տրվում է մեկ ժամ գործող HttpOnly, SameSite=Strict cookie։ Token-ը նորից ստուգվում է ամեն հարցման ժամանակ։ «Դուրս գալ»-ը մաքրում է տվյալ բրաուզերի սերվերային մուտքը։ Սերվերի վերագործարկումից հետո նորից բացիր հաշվի էջը։

Հոդվածների և ապրանքների ընթերցումը, կապի ձևը և ուսումնական պատվերի ուղարկումը հանրային են։ Վճարումներ չկան։ Սերվերը դեռ աշխատում է միայն 127.0.0.1 հասցեով։ Հանրային տեղադրումը առանձին աշխատանք է՝ HTTPS, Secure cookie, հարցումների սահմանափակում և hosting-ի կարգավորում։

Ստուգումները՝ `node --test backend-learning/*.test.mjs`։ Թեստերն օգտագործում են ներմուծված կեղծ verifier, իսկ գործարկվող սերվերը միշտ ստուգում է իրական Supabase մուտքը։
