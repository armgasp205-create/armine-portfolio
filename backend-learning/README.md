# Տեսանելի Node.js backend՝ քո React պլանավորիչի մեջ

## Բացել կայքը

Խանութի, բլոգի, dashboard-ի և կապի ձևի նոր կապերը նկարագրված են [PORTFOLIO-BACKEND.md](PORTFOLIO-BACKEND.md)-ում։ Դրանց կառավարումը՝ http://127.0.0.1:3002/backend-admin.html ։

Հիմնական պանակի տերմինալում՝

```powershell
npm.cmd --prefix react-learning run build:portfolio
node scripts/prepare-static.mjs
node backend-learning/server.mjs
```

Բացիր **http://127.0.0.1:3002/react-planner/#/backend**։ Այստեղ սովորական կայք է՝ առաջադրանք ավելացնելու, խմբագրելու, ավարտելու և ջնջելու կոճակներով։ JSON-ի էջ կամ տերմինալի POST հրաման պետք չէ։

## Ինչն է backend-ը

1. React-ի ձևում գրում ես առաջադրանք ու սեղմում «Ավելացնել սերվերում»։
2. React-ը POST հարցում է ուղարկում `/api/tasks` հասցեին։
3. Node.js-ը ստուգում է տեքստը և կարևորությունը, ստեղծում ID-ն։
4. SQLite բազան պահում է առաջադրանքը `backend-learning/data/tasks.sqlite` ֆայլում։
5. Սերվերը պատասխանում է, իսկ React-ը նորից կարդում և ցուցադրում է ցանկը։

**Տվյալները չեն պահվում այս էջի localStorage-ում։** Էջը կամ սերվերը վերագործարկելը չի ջնջում բազան։ «Ջնջել»-ը իսկապես հեռացնում է առաջադրանքը բազայից։

## Ֆայլերը

- `server.mjs` — Node.js սերվեր, API, ստուգում և SQLite հարցումներ։
- `../react-learning/src/pages/BackendPage.tsx` — տեսանելի React էջ և fetch հարցումներ։
- `data/tasks.sqlite` — տեղական տվյալների բազան, Git-ում չի պահպանվում։
- `server.test.mjs` — վավերացում, խմբագրում, պահպանում վերագործարկումից հետո և ջնջում։
- `browser.test.mjs` — իրական React էջի գործողությունների ստուգում։

## API

- POST `/api/tasks/import` — ստանում է version 1 JSON պատճենը (մինչև 1 ՄԲ և 1000 գրառում), ստուգում ամբողջը և մեկ transaction-ով ավելացնում նոր ID-ներով գրառումները։ Նույն ID-ն բաց է թողնվում նաև այն դեպքում, երբ առկա առաջադրանքն աղբարկղում է։ Պատասխանը ներառում է `imported`, `skipped`, `view`։ Սխալ ֆայլի կամ 100 ակտիվ առաջադրանքի սահմանի գերազանցման դեպքում ոչինչ չի գրվում։

«Ներբեռնել տվյալները» բաժինը հիմնական ցանկը կամ աղբարկղը ներբեռնում է JSON կամ CSV ֆայլով։ Այն ներառում է բաժնի բոլոր գրառումները՝ անկախ որոնումից ու էջավորումից։ JSON-ի պատճենը ունի տարբերակ, ամսաթիվ և առաջադրանքներ։ CSV-ն հայերենով բացելու համար պարունակում է UTF-8 BOM։ JSON պատճենը հնարավոր է վերադարձնել «Վերադարձնել JSON պատճենը» ձևով։

- GET `/api/tasks/export?format=json&view=tasks` — հիմնական ցանկի JSON պատճենը։
- GET `/api/tasks/export?format=csv&view=trash` — աղբարկղի CSV աղյուսակը։

Առաջադրանքն այժմ կարող է ունենալ `due` ժամկետ՝ `YYYY-MM-DD` ձևաչափով։ Դատարկ տողը նշանակում է՝ առանց ժամկետի։ Կայքում առկա են «Այսօր», «Ուշացած», «Առանց ժամկետի» զտիչներն ու մոտակա ժամկետով դասավորումը։ Ավարտված առաջադրանքը ուշացած չի համարվում։

- GET `/api/tasks` — ցանկը։
- GET `/api/tasks?q=սովորել&status=active&priority=high&sort=priority&page=1&limit=5` — որոնում, զտում, դասավորում և էջավորում SQLite-ում։ Պատասխանը ներառում է `tasks`, `pagination` և ընդհանուր `stats`։
- POST `/api/tasks` — նոր առաջադրանք։
- PATCH `/api/tasks/:id` — տեքստի, կարևորության կամ ավարտված լինելու փոփոխություն։
- DELETE `/api/tasks/:id` — այժմ տեղափոխում է աղբարկղ՝ առանց վերջնական ջնջելու։
- GET `/api/tasks?view=trash` — աղբարկղի ցանկը՝ որոնմամբ և էջավորմամբ։
- POST `/api/tasks/:id/restore` — վերականգնում՝ նույն տեքստով, կարևորությամբ, ժամկետով և կարգավիճակով։

Աղբարկղի տվյալները պահվում են SQLite-ում նաև սերվերը վերագործարկելուց հետո։ Հին բազան ավտոմատ ստանում է `deleted_at` դաշտը՝ առանց հին առաջադրանքները ջնջելու։ Մշտական ջնջման կոճակ այս փուլում չկա։

## Ստուգում

```powershell
node --test backend-learning/server.test.mjs
node --test backend-learning/browser.test.mjs
```

Node.js 24-ը բավարար է․ լրացուցիչ backend փաթեթներ պետք չեն։ Կանգնեցնելու համար՝ Ctrl + C։

Սա քո համակարգչում աշխատող, մեկ օգտատիրոջ ուսումնական տարբերակն է։ Սերվերը բաց է միայն `127.0.0.1`-ի վրա և բազան չի սպասարկում որպես ֆայլ։ Գործող Supabase պլանավորիչը շարունակում է առանձին աշխատել։ GitHub Pages-ը Node.js չի գործարկում․ այս նոր էջի backend-ը համացանցում դեռ հրապարակված չէ։ Դրա համար հետո պետք է սերվերային հոսթինգ և օգտատերերի թույլտվություններ։
