# Backend-ը չորս նախագծերում

## Բացել

```powershell
npm.cmd --prefix react-learning run build:portfolio
npm.cmd --prefix next-blog run build
node scripts/prepare-static.mjs
node backend-learning/server.mjs
```

- Կառավարում՝ http://127.0.0.1:3002/backend-admin.html
- Պորտֆոլիո՝ http://127.0.0.1:3002/index.html
- Խանութ՝ http://127.0.0.1:3002/shop.html
- Dashboard՝ http://127.0.0.1:3002/dashboard.html
- Բլոգ՝ http://127.0.0.1:3002/next-blog/
- Պլանավորիչ՝ http://127.0.0.1:3002/react-planner/#/backend

## Ինչն է կապված

**Խանութ։** Ապրանքները կարդացվում են SQLite-ից։ Կառավարման էջում կարելի է փոխել անունը, նկարագրությունն ու գինը։ «Պատվիրել»-ը ստեղծում է տեղական պատվեր՝ առանց վճարման կամ առաքման։ Սերվերը գինը վերցնում է ապրանքի բազայից։ Նույն հարցման կրկնումը երկրորդ պատվեր չի ստեղծում։

**Dashboard։** Ցուցադրում է բազայում պահված պատվերները։ Կառավարումից փոխված կարգավիճակը կերևա dashboard-ը թարմացնելուց հետո։ Գումարները պատվերների արժեքներն են, ոչ վճարման համակարգից հաստատված մուտքեր։ Հին պատվերի գինը չի փոխվում ապրանքի գնի փոփոխությունից։

**Բլոգ։** Կառավարման էջում ավելացրած և խմբագրած հոդվածները կերևան տեղական Next.js բլոգի ցանկում։ Ընթերցման էջը `blog-article.html?id=...` է՝ տվյալները backend-ից բեռնելով։ Next.js-ի նախկին ստատիկ հոդվածների էջերը մնում են նախագծում։ «Հեռացնել ցանկից»-ը թաքցնում է հոդվածը, բազայում դրա գրառումը պահպանվում է։

**Կապ։** Տեղական պորտֆոլիոյի ձևը հաղորդագրությունները պահում է SQLite-ում։ Կառավարումից կարելի է նշել կարդացված կամ չկարդացված։ Էլեկտրոնային նամակ չի ուղարկվում։

Տվյալները պահվում են `data/tasks.sqlite`-ում՝ առանձին `products`, `orders`, `posts`, `messages` աղյուսակներում։ Նախկին առաջադրանքները մնում են իրենց աղյուսակում։ Թեստերի տվյալները իրական բազայում չեն գրվում։

## Տեղական տարբերակ

Կառավարման էջում կան բաժինների նավիգացիա, բոլոր ցանկերի ընդհանուր որոնում, պահպանվող բաց/մուգ թեմա և սերվերի վիճակի ցուցիչ։ `GET /api/health`-ը ստուգում է բազայի հասանելիությունը, իսկ `GET /api/activity`-ը վերադարձնում վերջին 100 հաջող փոփոխությունները՝ առանց հարցումների բովանդակության կամ հաղորդագրությունների անձնական տվյալների։

Ակտիվ կառավարման էջը յուրաքանչյուր 30 վայրկյանը մեկ թարմացնում է ցանկերը, եթե ձևում փոփոխություն չի գրվում։ Dashboard-ը թարմացնում է պատվերները նաև կառավարման փոփոխությունից և ներդիրին վերադառնալուց հետո։ Չպահպանված ձևերը չեն զրոյացվում։

Սա մեկ համակարգչում աշխատող ուսումնական համակարգ է։ Կառավարումը դեռ չունի առցանց մուտք ու դերեր։ Սերվերը լսում է միայն 127.0.0.1 հասցեով, ստուգում է հարցումների աղբյուրը և source/database ֆայլերը չի սպասարկում։ Այս տարբերակը դեռ հրապարակված չէ համացանցում։ GitHub Pages տարբերակը շարունակում է նախկին ցուցադրական և Formspree վարքը․ Node.js այնտեղ չի գործարկվում։

## Ստուգումներ

```powershell
node --test backend-learning/server.test.mjs backend-learning/browser.test.mjs backend-learning/portfolio.test.mjs backend-learning/portfolio-browser.test.mjs
```

Ստուգվում են նաև վերագործարկումից հետո պահպանումը, գների ստուգումը, կրկնվող պատվերը, սխալ հարցումների մերժումը և էջերի միջև իրական կապը։
